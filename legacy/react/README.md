# Original React prototype

This is the preserved browser implementation from commit `565e819`, before the Ren’Py migration. It contains the studio splash, opening player, harbor scene, original animated Kite and perception layers, local browser speech, and simulated controller tests. It has no museum chapter and is no longer the publishing target.

From this directory, use Node.js 22.12+:

```sh
npm ci
npm test
npm run dev
```

Active story work belongs in the root `game/` Ren’Py project. The original README is preserved in `README.original.md`; its paths and publishing instructions describe the old layout.
